## 0. Цель

Работающий рынок **одного актива**: планировщик событий, агенты, стадность, концентрация капитала, лог прогона. На нём проводится исследование исходной пропозиции (стадность × концентрация капитала → стабильность). Это **страховка проекта**: оно не зависит от данных и графа.

## 2. Планировщик событий (DES)

- Очередь `heapq` из `(time, seq, event)`; `seq` — счётчик, чтобы при равном времени порядок был детерминированным.
- Время: 1 сессия = 1,0. События: пробуждение агента, истечение GTD (`gateway.expire`), снимок стакана (каждые `sample_dt`), начало сессии (обновление внешних сигналов), управляющее событие (живой режим, шоки).
- Пробуждения: интервалы между решениями агента — экспоненциальные, интенсивность зависит от типа агента (параметр конфигурации).
- **Случайность:** `numpy.random.SeedSequence(seed)` → отдельный генератор на каждый компонент (агенты, сеть, пробуждения). Один и тот же seed и конфиг → **идентичный лог** (тест).

```text
init: портфели, агенты, сеть знакомств, очередь (первые пробуждения, снимки, сессии)
while очередь не пуста и time < n_sessions:
    event = heappop(queue); now = event.time
    обработать событие → новые события в очередь
    gateway.drain_fills() → recorder
```

## 3. Агенты (одноактивная версия)

| Тип | Решение |
|---|---|
| Оценщик | постоянная оценка $V_a = P_0 (1 + e_a)$; сигнал $b = \operatorname{clip}((V_a - P)/(\gamma P), -1, 1)$ |
| Трендовый | $b$ — масштабированное изменение цены за последние $k$ сессий |
| Шумовой | $b$ случайно из $[-1, 1]$ |
| Маркет-мейкер | котировки вокруг середины спреда (или последней цены) со спредом; сдвиг котировок при большом запасе акций; ограниченные деньги и акции |

**Стадность** (сеть знакомств, фиксированная на прогон): $s_i = (1 - h)\, b_i + h\, \bar d_{N_i}$, где $\bar d_{N_i}$ — средний **опубликованный** сигнал соседей (−1 / 0 / +1) с ограниченным сроком годности; просроченный считается 0.

**Решение → заявка:**
1. снять свою предыдущую активную заявку;
2. $s > $ порог → покупка; $s < -$порог → продажа; иначе ничего;
3. размер $q = \lfloor \rho\, \lvert s \rvert\, W / P \rfloor$ ($W$ — стоимость портфеля), ограничен ресурсами;
4. пассивная лимитная заявка у лучшей цены или агрессивная IOC с защитной ценой — по правилу из конфигурации;
5. `gateway.place(...)`; при `REJECTED_FUNDS` — ничего.

**Концентрация капитала $C$:** фонды получают долю $C$ денег и акций инвесторов, retail — остальное; общее количество денег и акций, численность групп и доли стратегий одинаковы во всех вариантах; маркет-мейкеры отдельно.
