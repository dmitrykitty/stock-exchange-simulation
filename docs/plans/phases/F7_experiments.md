# F7. Experiments — эксперименты

**Владельцы:** S (runner и конфиги), O (параллельный запуск), D1 и D2 (анализ)
**Срок:** недели 7–8
**Зависит от:** F6 (M3). **От неё зависят:** F8, F10.

---

## 1. Runner

- `marketsim.experiments.config.load_config(path)` → `expand(exp)` → список `RunSpec(config, seed, overrides)` (готово, K4).
- `ExperimentRunner` (S + O): запускает `sim.api.run` для каждого `RunSpec` параллельно (`multiprocessing`, прогоны независимы), пишет в `runs/<experiment>/<run_id>/`, умеет продолжать после обрыва (пропускает готовые).
- После прогонов — сводная таблица: одна строка на прогон, колонки = параметры сетки + seed + метрики (D1).

## 2. Протокол (замораживается до основного запуска)

- метрики и их определения (`docs/model/model_description.md`, раздел 8);
- прогрев (`warmup_sessions`), длина, шаг снимков;
- seeds основного запуска — **новые**, не те, что в пилоте;
- правило выбора «показательных» прогонов для отчёта и демо: медиана и 90-й перцентиль метрики, а не «самый красивый».

## 4. Анализ

- Единица статистики — **прогон**, а не сделка: тысячи сделок одного прогона не заменяют seeds.
- Для каждой конфигурации: распределение метрики (box plot с точками прогонов), медиана, разброс.
- Сравнение с контролем: разница и 95%-й доверительный интервал **bootstrap по прогонам**.
- Heatmaps «фактор × фактор» для главных метрик; одинаковая шкала цветов для одной метрики.
- Notebook `notebooks/03_experiments.ipynb`.
