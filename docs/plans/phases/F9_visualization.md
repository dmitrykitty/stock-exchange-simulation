# F9. Visualization — дашборд и демонстрация

**Владельцы:** D1 (каркас, графики, сравнение экспериментов), O (панель стакана, живой режим)
**Срок:** replay одного актива — с недели 4; сеть — неделя 6; живой режим — неделя 7; полировка — неделя 9
**Зависит от:** K3 (лог). Визуализация читает **только** логи прогонов и ничего не импортирует из кода симуляции.

---

## 1. Режимы

- **Воспроизведение (replay):** записанный прогон, скорость ×1…×100, пауза, шаг по событию, замедление внутри сессии (чтобы была видна волна).
- **Живой режим:** симуляция идёт сейчас; кнопки «нефть ±30%», «обвал компании X», ползунок стадности $h$. Каждое действие пишется как событие в таблицу `events` лога (требование курса: изменение параметров во времени).

Скорость показа и частота обновления **не влияют** на результат симуляции.

## 2. Панели

| Панель | Данные из лога | Что показывает |
|---|---|---|
| Внешние сигналы | сценарий K2 | нефть, газ, металлы, индекс с курсором времени |
| Граф | граф K2 + `trades`/`book` | узлы — компании и сырьё, толщина ребра — вес, цвет узла — изменение цены; волна по графу |
| Мини-графики | `book`, `valuations` | цена (линия) и эталон (пунктир) каждой компании |
| Агенты | `signals` | доли покупателей / продавцов по акции, стадные «вспышки» |
| Детали акции | `trades`, `book`, `orders`, `events` | свечи с объёмом, стакан (лучшие уровни), лог событий |
| Сравнение экспериментов | сводные таблицы F7 | heatmaps, box plots, граф «заложенный против восстановленного» |

Свечи строятся из **всех** сделок интервала; интервал без сделок — пропуск, а не плоская свеча; пустая сторона стакана помечается явно.

## 3. Технология

Plotly (зависимость `viz` в `pyproject.toml`); веб-интерфейс — Dash или аналог (решает D1). Живой режим: бэкенд O запускает симуляцию в отдельном процессе и отдаёт снимки.

## 4. Готово, когда

- [ ] replay одного актива: свечи, стакан, сигналы, лог;
- [ ] сетевой режим: видна волна по графу на прогоне F6;
- [ ] живой режим с кнопками шоков и ползунком $h$, события в логе;
- [ ] заранее записанные прогоны для защиты, выбранные по правилу F7 (медиана / перцентиль).
