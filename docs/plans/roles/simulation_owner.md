# Роль S: симуляция и агенты

**Твои фазы:** [F4](../phases/F4_single_asset_market.md) → [F5](../phases/F5_graph_valuers.md) → [F6](../phases/F6_full_network.md) → [F7](../phases/F7_experiments.md).
**Ты владеешь:** K3 (лог прогона, `src/marketsim/sim/log_schema.py`) и K4 (конфигурация, `src/marketsim/experiments/config.py`; секция `agents` — целиком твоя).
**Ты пользуешься:** K1 (шлюз — единственный способ торговать), K2 (граф, внешние сигналы), данными через `marketsim.data.api`.

Ты на **критическом пути**: агенты нужны во всех вехах. Остальные снимают с тебя всё, что не агенты: D1 — метрики, O — скорость и параллельный запуск, D2 — оценщики по графу (с недели 5).

## Что делать

| Неделя | Задачи | Результат |
|---|---|---|
| 1 | день 3 — K1 с O; планировщик событий (очередь, seed, детерминизм); каркас агента; просмотреть K3/K4 | планировщик гоняет «пустых» агентов |
| 2 | оценщик, трендовый, шумовой, маркет-мейкер на `PyExchange`; запись лога K3 | пример лога для D1 и O |
| 3 | стадность (сеть знакомств), концентрация $C$, пилот E0 | **M1** |
| 4 | протокол E1–E3 → запуск | **M2** |
| 5 | оценщики по графу (с D2), несколько активов, E4 | волна на цепочке |
| 6 | полная сеть (с D2 и O) | **M3** |
| 7–8 | runner, протокол, E5–E7 | результаты |
| 9 | разбор механизмов (ablation) | **M4** |
