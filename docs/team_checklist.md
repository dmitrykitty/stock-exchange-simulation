## 3. Контракты: кто владеет, кто пользуется

| Контракт | Владелец | Пользуются | Что нельзя менять без процедуры |
|---|---|---|---|
| K1 биржа и шлюз | O | S | сигнатуры, типы массивов, коды статусов, семантику сопоставления |
| Данные | D1, D2 | все | имена функций `load_*`, имена файлов, колонки, типы |
| K2 граф и внешние сигналы | D2 | S, D1 | формат `nodes.csv` / `edges.csv`, сигнатуры `structure` / `weights` / `reference` |
| K3 лог прогона | S | D1, O | таблицы и колонки лога, ключи `meta.json` |
| K4 конфигурация | S | все | верхние поля `RunConfig` (секция `agents` свободная) |

**Как менять контракт:** PR с меткой `contract-change`; в том же PR — код контракта, тесты в `tests/contracts/`, `docs/model/contracts.md`; одобряют владелец **и все**, кто им пользуется. Добавить новую необязательную колонку или функцию — достаточно одобрения владельца.

## 4. Правила, которые соблюдаем всегда

- [ ] Код, комментарии, docstrings, коммиты, ветки, имена файлов — **на английском**. README — на английском. Документы в `docs/` — на русском. Пропозиция и отчёт — на польском.
- [ ] В `main` напрямую **не пушим**. Ветка `<область>/<что-делаем>` (`engine/…`, `data/…`, `graph/…`, `sim/…`, `agents/…`, `docs/…`) → PR → одобрение владельца области → зелёный CI → squash merge.
- [ ] Коммиты маленькие, сообщение в одну строку: `data: fetch FRED series`.
- [ ] **Не меняем чужие контракты** и **не правим тесты контрактов**, чтобы прошёл свой код.
- [ ] Данные читаем только через `marketsim.data.api`, записываем только через `write_table`.
- [ ] Не коммитим `data/raw/`, `data/processed/`, `runs/`, ключи, пароли, личные e-mail.
- [ ] Случайность — только через `numpy.random.Generator` от seed прогона. Цены — целые тики, деньги — целые центы.
